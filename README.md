# Simulateur de Nettoyage – Mon Bureau Tout Propre 🧹✨

Ce dépôt contient le projet **simulateur de prestations de nettoyage de bureaux** pour l’entreprise **Mon Bureau Tout Propre**.  
Il permet aux clients de **calculer eux-mêmes le coût d’une prestation** directement sur le site internet.

## 📝 Objectif

- Fournir une **expérience utilisateur claire et intuitive**.
- Permettre aux clients de **simuler rapidement le coût** d’un nettoyage de bureau.
- Faciliter la **prise de décision et le contact avec l’entreprise**.

## 💻 Fonctionnalités

- Formulaire interactif pour sélectionner :
  - Type de prestation (standard, intensive, spéciale)
  - Fréquence de nettoyage (ponctuelle, hebdomadaire, mensuelle)
- Calcul automatique du prix estimatif.
- Affichage clair du résultat avec possibilité de contacter l’entreprise.
- Compatible avec les standards HTML/CSS et bonnes pratiques d’accessibilité.

## 🛠️ Technologies utilisées

- **HTML5** : structure de la page
- **CSS3** : mise en forme et design responsive
- **JavaScript** : calcul du prix en temps réel et interactions utilisateur
